## 外贸服务器配置怎么选

### 按客户地区选节点

- **客户分布全球或主要在亚洲**：选香港，延迟稳定
- **客户集中在欧美**：选美国，离得近延迟更低
- **既有海外客户又需要国内访问**（比如供应商要看网站）：香港 CN2 GIA 或美国 CN2 GIA 三网优化

### 按预算选线路

- **预算很紧（月付50元以下）**：美国 9929/CMIN2 原生双 ISP 的 34.8元或 50元套餐，或美国 BGP 的 34.8元套餐（流量更多）
- **预算中等（月付50-200元）**：香港 CN2 GIA Plus/Pro（49-89元）或美国 CUII 9929（39-79元）
- **追求速度稳定不在乎价格**：香港 CN2 GIA Max 以上（198元起）或美国 CN2 GIA 三网优化（99元起）

### 按流量和带宽选配置

一个普通外贸产品站（50-100 个产品页面，每页 2-3MB），每天 200 个 UV，一个月大概用 50-80GB 流量。如果你的网站图片很多或有视频，流量需求会翻倍。

- **小型外贸站（日均 100-300 UV）**：500GB-1TB 月流量 + 50-100Mbps 带宽
- **中型外贸站（日均 300-1000 UV）**：1-2TB 月流量 + 100Mbps 带宽
- **大型外贸站或多站运营**：3TB 以上月流量 + 200Mbps 以上带宽

ZoroCloud 的流量超出后会怎么样？资料里没有明确说明是限速还是额外收费。建议选套餐时留 30-50% 的流量余量，或者购买前咨询客服确认超流量后的处理方式。

### CPU 和内存怎么选

- **纯静态页面或轻量级 WordPress**：1核1GB 够用
- **WordPress + WooCommerce 电商站（产品数小于 1000）**：2核2GB 起步
- **产品数超过 5000 或有复杂筛选功能**：4核4GB 以上
- **多个站点共用一台服务器**：按站点数量叠加，3-5 个小站可以用 4核4GB

### 不同线路类型的实际使用场景

**CN2 GIA 三网优化**适合需要兼顾海外客户和国内供应商访问的外贸站。比如你在深圳做外贸，客户在欧美，但工厂在东莞，工厂老板要经常登录后台上传产品图片，这时候三网优化就有用了。

**9929/CMIN2 双线路优化**主要照顾联通和移动用户。如果你的外贸站同时做国内批发（比如在 1688 上也卖），而且你发现访客里联通和移动占比很高，这个线路性价比最高。

**原生双 ISP**的优势是 IP 干净，不会被 TikTok、Instagram 之类的平台识别为数据中心 IP。如果你做社交媒体营销、需要在服务器上运行自动化工具，原生双 ISP 比普通 VPS 安全。

**住宅 IP**（香港 BGP 和美国 ATT）是最接近真实用户的网络环境。跨境电商平台（亚马逊、eBay）对账号登录 IP 很敏感，用住宅 IP 可以降低被风控的概率。但住宅 IP 不支持退款，而且贵，不是必需别碰。
